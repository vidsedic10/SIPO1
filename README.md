Kaj je operacijski sistem?
Operacijski sistem  je del sistemske programske opreme, ki upravlja z uporabniško programsko opremo in s strojno opremo. Deluje kot posrednik med uporabnikom in strojno opremo. In nam omogoča, da lahko z računalnikom sploh kaj počnemo. 

3 naloge operacijskega sistema:
o	Upravljanje s procesorjem in pomnilnikom
o	Upravljanje z datotečnimi sistemi
o	Časovno razporejanje opravil


Windows vs Mac OS vs Linux:

Datotečni sistemi:
Windows drugače shranjuje datoteke, kot Mac OS in Linux. Windows uporablja diske oz. drives po navadi C in D na katerih so shranjene vse datoteke na računalniku in ločene zunanje diske, kot so USB ključki.
Mac in Linux imata podoben datotečni sistem, ki izhaja iz UNIX-a. V teh operacijskih sistemih ni diskov – vse v računalniku se šteje za datoteko (tudi zunanje naprave) in vse datoteke so organizirane v imenike, ki izhajajo iz enega samega glavnega imenika.
Lupine:
Tako Linux kot Mac imata Bash kot privzeto lupino, medtem ko ima Windows svojo lupino, ki uporablja drugačno sintakso.
Package managers:
Mac in Linux imata privzeto nameščene upravljalnike paketov, med tem ko ga Windows nima. Upravitelj paketov je programska oprema, ki omogoča namestitev, posodabljanje in odstranjevanje programov iz terminala z vnosom le nekaj ukazov.
Stroški:
Linux ima brezplačno licenco, med tem ko Windows ima plačljivo in Mac OS ima tudi plačljivo, ampak je na voljo samo na Mac napravah.
Kakovost in združljivost strojne opreme:
Apple sam razvija strojno in programsko opremo, kar zagotavlja vrhunsko združljivost in zmogljivost njegovih računalnikov. Nasprotno pa sta Windows in Linux odvisna od strojne opreme, ki jo izbere uporabnik, vendar ponujata svobodo namestitve na poljubne naprave. 

Združljivost programske opreme:
Ker je Windows bolj razširjen od Mac-a in Linuxa je posledično več programov, ki podpira samo Windows, vendar se to v zadnjih letih zmanjšuje.

Kaj pomeni, da se naloži ob zagonu:
Pomeni, da se operacijski sistem naloži ob zagonu in se koda za OS iz SSD ali HDD prenese na RAM, kjer lahko začne dejansko delovati. V ang se reče temu booting.

Kaj je gonilnik:
Gonilnik je programska oprema, ki računalniku omogoča komuniciranje s strojno opremo ali V/I napravami.

Kje jih potrebujemo:

o	Operacijskem sistemu- so po navadi že vgrajeni (generični gonilniki) in so nujni za delovanje strojne opreme
o	Perifernih napravah- kot so miške, tipkovnice in tiskalniki
o	Pomnilniških napravah- kot so SSD in HDD, da se lahko podatki sploh zapisujejo

HDD vs SSD:

HDD je starejša, tehnologija, ki uporablja magnetne plošče za zapisovanje podatkov in ima vrtečo glavo za zapisovanje. SO cenejši, lahko shranimo več TB, ima daljšo življenjsko dobo kot SSD in so zelo občutljivi na premike.

SSD so novejša tehnologija, ki uporablja elektronski čip torej nima vrtečih delov kot HDD. Štejemo ga med flash pomnilnike in je random access. Je bistveno hitrejši , dražji, so tišji, bolj energetsko varčni in bolj odporni na padce.

Particija:
Je virtualno ločen del trdega diska, to se uporablja na primer pri virtualnih računalnikih- virtualnemu računalniku dodeliš nek del od celega trdega diska in ta dodeljen manjši del je particija
